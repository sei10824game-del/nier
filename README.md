# NieR:Automata Units (Minecraft 1.20.1 / Forge 47.3.0)

All combat units of NieR:Automata as entities with skill-driven attacks, keyframed multi-bone animations and form changes.
Units: YoRHa 2B / 9S / A2, YoRHa soldiers, 2E, Commander, Operators, Resistance, Anemone, Jackass, Pascal, Devola/Popola, Emil (+Hacked), Pod,
8 bosses (Adam, Eve, Engels, Marx, Hegel, Grun, Simone, Red Girls), 40 machine lifeform variants.

Hostility: Machines attack players, androids and all non-NieR mobs; Androids attack Machines and non-NieR mobs; all other mobs attack NieR units.

## Build / run (JDK 17)
    ./gradlew build          # jar in build/libs/
    ./gradlew runClient      # needs a display; spawn eggs are in the "NieR:Automata Units" creative tab
    ./gradlew runServer

Textures are generated by scripts in `tools/gen/` (`python3 tools/gen/<script>.py`, `python3 tools/lang.py` for lang files); see `docs/UNIT_GUIDE.md`.
